== Zombie Apocalypse - Project Status ==

=== What's Been Built (Phase 1 + Phase 2) ===

### Project Infrastructure
- Project structure with client/, server/, shared/ directories
- Express + Socket.IO server on port 3000
- In-memory database (Supabase-ready)
- Shared constants file for game config and socket events
- .env.example for configuration

### Frontend (Client)
- Cinematic main menu: fog overlays, blood particles, glowing logo, team selection
- Loading screen: animated 6-step sequence with progress bar, biohazard icon
- Leaflet map: dark CartoDB tiles, custom circular player icons
- Player rendering: circle + direction arrow + name + health ring
- HUD: health bar, compass, player counts, GPS accuracy/speed, hearts, stamina
- Sound system: Web Audio API (heartbeat, infection, item pickup, etc.)
- Device orientation: compass tracking (phone heading)
- Settings panel: audio sliders, render distance, quality, fullscreen
- PWA support: manifest, service worker, install prompt
- Notification system: toast-style alerts

### Game Mechanics (Server)
- Player system: join, position updates, persistent connection
- Infection logic: 15m radius, server-authoritative distance calculation
- Safe zones: entry/exit detection, health regen (2HP/2sec)
- Item system: mech parts (3 required), health packs, supplies
- Item pinging: items flash location every 5 minutes
- Radio crafting: 3 mech parts → craft radio → spawn extraction point
- Helicopter extraction: walk to extraction point, max 4 escape, 100 coins reward
- Zombie vision: red pulse overlay + heartbeat within 50m of survivor
- Anti-cheat: speed limit (30 km/h), teleport detection
